# HWP Copilot · 한글 보고서 도우미

한글 문서 옆에서 AI와 함께 보고서를 작성하는 Windows 데스크톱 앱입니다. 문서의 내용을 참고해 초안을 만들고, 검토한 글을 실제 한글 문서에 추가하거나 선택한 문장과 교체할 수 있습니다.

개인과 팀이 보고서 작성에 활용하기 위한 사이드 프로젝트입니다. 한글 창을 따라다니는 별도의 보조 패널로 실행됩니다.

## 주요 기능

- 한글 창 옆 패널 배치, 창 이동·최소화 연동, 독립 창 전환
- 대화형 화면, 질문창 바로 위의 사용량 바와 하단 입력창 고정
- AI·한글 연결·문서 문맥·창 배치는 설정 창에서 관리
- 문서 전체 또는 선택 영역 읽기
- 기존 보고서 파일을 선택해 연결하고 바로 읽기
- AI 초안 생성, 직접 수정, 커서 위치에 추가·선택 문장 교체
- OpenAI, Claude, Gemini, OpenAI 호환 API 및 로컬 AI 연결
- 여러 연결 설정 저장 및 전환 — API 키는 저장하지 않음
- 적용 전 문서·커서·선택 영역 변경 확인

## 빠르게 실행하기

### 실행 파일로 사용

`HWP-Copilot-0.3.1-x64.exe`를 더블클릭합니다. 직접 빌드했거나 실행 파일이 포함된 프로젝트를 받은 경우 `bin/` 폴더에 있습니다. Node.js는 필요하지 않습니다.

GitHub에서 소스만 내려받았다면 EXE는 포함되어 있지 않습니다. 배포자가 Releases에 실행 파일을 올렸다면 해당 파일을 받거나, 아래 방법으로 소스에서 실행하세요.

필요한 환경은 **Windows x64**, **자동화 기능을 지원하는 한글 데스크톱**, **사용할 AI 서비스의 API 키**입니다. 로컬 AI 서버가 인증을 요구하지 않는 경우 키를 생략할 수 있습니다.

### 소스에서 실행

Node.js **22.12 이상**을 설치하고 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
npm.cmd ci
npm.cmd start
```

이미 의존성을 설치했다면 `npm.cmd start`만 실행하면 됩니다. 브라우저를 따로 열 필요가 없습니다. `src/hwpcopilot.js`는 개발용 웹 서버이며, 데스크톱 앱의 시작점은 `src/desktop/main.js`입니다.

## 사용 순서

1. 오른쪽 위 **설정**에서 **AI 연결 설정**을 펼치고, 키로 조회된 모델을 선택합니다.
2. 설정을 닫고 아래 입력창에서 질문합니다. `Enter`로 전송하고 `Shift+Enter`로 줄을 바꿉니다.
3. 이전 답변을 이어서 질문할 수 있습니다. 대화 영역만 스크롤하며 사용량 바와 입력창은 화면 아래에 유지됩니다.
4. 문서에 넣으려면 설정에서 **기존 파일 선택해서 연결**을 누르고, 한글의 파일 선택 창에서 작업할 문서를 고릅니다. 선택한 파일을 바로 읽어 연결합니다.
5. 커서나 선택 영역을 정한 뒤 설정에서 **문서 읽기**를 누르고 적용 방식을 고릅니다.
6. 대화의 답변을 검토·수정하고 **문서에 적용**을 누릅니다. **파일 저장**은 설정에 있습니다.

일반 질문은 한글 연결 없이도 가능합니다. 문서 문맥을 보낼 때와 답변을 적용할 때는 문서 읽기가 필요합니다. 문서를 읽은 뒤 커서나 선택 영역을 바꾸면 다시 읽으세요. 적용 자체는 파일을 자동 저장하지 않습니다.

다른 파일로 바꾸려면 **기존 파일 선택해서 연결**을 다시 누르세요. 새 문서 작업은 **한글 창만 연결 / 새 문서 작업**으로 시작할 수 있습니다. 이미 다른 한글 창에서 열어 편집 중인 파일은 그 창에서 먼저 저장한 뒤 선택하세요. 기존 창의 저장하지 않은 내용을 가져오는 기능은 아닙니다.

자세한 패널 조작과 AI 설정은 [사용 안내](docs/팀원-시작하기.md)를 참고하세요.

## 호환성과 현재 범위

| 환경 | 상태 |
| --- | --- |
| 한글 2018 / 10.0.0.14850 | 실제 새 문서 읽기·삽입·한국어 선택 교체·커서 변경 감지·되돌리기 검증 |
| 다른 Windows 데스크톱 한글 버전 | 공통 자동화 API를 사용하도록 구현, 버전별 실기기 검증 필요 |
| 한글 뷰어·웹한글·macOS·모바일 한글 | 지원하지 않음 |

일반 본문의 **텍스트 편집**을 지원합니다. 표·이미지·글꼴·문단 스타일 생성은 포함하지 않으며, 교체 구간의 세부 서식 보존을 보장하지 않습니다. 다른 버전이나 복잡한 문서는 사본으로 먼저 확인하세요.

API 어댑터·모델 목록·오류 구분·문서 편집 흐름 등의 자동 테스트를 포함합니다. 데스크톱 및 배포 EXE는 모의 AI·문서로 검증합니다. 유료 AI API 실호출과 한글의 저장 대화상자를 통한 저장은 별도 확인이 필요합니다.

## 데이터와 API 키

문서 내용은 기본적으로 AI에 보내지 않습니다. 사용자가 ‘선택 영역’ 또는 ‘문서 전체’를 고르고 초안 생성을 실행하면 지시와 해당 문맥을 설정된 API 주소로 전송합니다.

API 키는 현재 실행 중 메모리에서 사용하며 디스크에 저장하지 않습니다. 연결 설정에는 이름·API 형식·기본 URL·모델 ID만 저장합니다. 데스크톱 설정은 각 PC의 `%APPDATA%\HWP Copilot`에 보관됩니다.

대화는 현재 실행 중에만 유지하며, 최근 최대 10턴·60,000자를 다음 요청에 포함합니다. 사용량 바는 API가 보고한 응답 토큰과 직전 응답의 한도 헤더를 사용합니다. 한도가 없으면 퍼센트를 추정하지 않으며, 월간 결제 잔액을 표시하는 기능은 아닙니다.

## 프로젝트 구조

```text
hwpcopilot/
├─ src/
│  ├─ desktop/          Electron 앱, 실행기, 패널 배치
│  ├─ native/           한글 자동화 및 Windows 창 추적
│  ├─ public/           화면, 스타일, 아이콘
│  ├─ bridge.js         PowerShell 브리지
│  ├─ document-service.js
│  ├─ providers.js      AI API 어댑터
│  └─ hwpcopilot.js     개발용 웹 서버
├─ bin/                 EXE 및 빌드 결과 — Git 제외
├─ test/                자동 테스트
├─ docs/                사용·개발·배포 안내
├─ artifacts/           테스트 결과 — Git 제외
├─ package.json
└─ package-lock.json
```
