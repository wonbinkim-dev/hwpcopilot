# 사용 안내

## 1. 앱 실행

`HWP-Copilot-0.3.1-x64.exe`를 더블클릭하세요. 프로젝트 폴더와 함께 받았다면 `bin/`에 있습니다. 실행 파일 하나만 받아도 되며 Node.js를 설치할 필요는 없습니다.

Windows x64와 한글 데스크톱이 필요합니다. 한글 뷰어·웹한글·macOS용 한글은 지원하지 않습니다. 포터블 앱은 실행할 때 임시 폴더에 프로그램을 풀기 때문에 초기 실행이 다소 느릴 수 있습니다.

## 2. 설정과 대화 화면

오른쪽 위 **설정**을 열면 한글 문서·AI 연결·문맥·적용 방식·창 배치를 변경할 수 있습니다. 평소에는 설정을 닫고 대화 화면을 사용하세요. 아래 입력창에서 `Enter`로 전송하고 `Shift+Enter`로 줄을 바꿉니다. 한국어 조합 중의 Enter는 바로 전송하지 않습니다.

이전 대화는 가운데 영역에서 스크롤합니다. **API 사용량 바는 질문창 바로 위**, **질문창은 화면 아래**에 고정되어 기록을 올려 봐도 자리를 유지합니다. 답변을 받는 동안 이전 기록을 보고 있으면 화면을 강제로 아래로 내리지 않습니다.

일반 질문은 AI만 연결해도 가능합니다. 문서에 답변을 적용하려면 아래 한글 연결과 문서 읽기도 진행하세요.

## 한글 문서 연결

설정에서 **기존 파일 선택해서 연결**을 누르세요. 한글의 파일 선택 창에서 작업할 `.hwp` 또는 해당 한글 버전이 지원하는 `.hwpx` 파일을 고르면 문서를 열고 바로 읽습니다. 화면 위쪽에 연결한 파일 이름이 표시되고 설정에서 전체 경로를 확인할 수 있습니다.

다른 파일로 바꾸려면 같은 버튼을 다시 누르세요. 저장하지 않은 수정 사항이 있으면 한글의 저장 확인창에서 처리합니다. 파일 선택을 취소하거나 열기에 실패하면 이전에 읽은 문서 상태는 만료되므로 **문서 읽기**를 다시 누르세요.

새 문서를 작성할 때는 **한글 창만 연결 / 새 문서 작업**을 사용합니다. 도우미는 자신이 연 한글 창을 제어합니다. 이미 다른 창에서 편집 중인 파일은 그 창에서 저장한 뒤 선택하세요. 다른 창의 저장하지 않은 내용을 가져오지는 않습니다.

처음 연결하면 문서와 패널을 나란히 배치합니다. 화면이 좁으면 패널이 문서 위에 겹칠 수 있습니다. 상단의 **창에 붙이기**를 끄면 패널을 자유롭게 옮길 수 있습니다.

## AI 연결 설정

설정의 **AI 연결 설정**을 펼쳐 API 형식, 기본 URL과 본인의 키를 입력하세요. 키 입력을 마치면 모델 목록을 조회합니다. ‘목록 불러오기’를 눌러 다시 조회할 수도 있습니다. ‘모델 선택’에서 사용할 모델을 고르세요.

| API 형식 | 기본 URL | 목록에서 선택할 모델 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | 계정에서 사용 가능한 모델 ID |
| Claude | `https://api.anthropic.com/v1` | 계정에서 사용 가능한 모델 ID |
| Gemini | `https://generativelanguage.googleapis.com/v1beta` | 계정에서 사용 가능한 모델 ID |
| OpenAI 호환 / 로컬 AI | 서버의 기본 URL, 초기값 `http://127.0.0.1:11434/v1` | 해당 서버에 설치·등록된 모델 ID |

모델 ID를 직접 입력하지 않습니다. 앱이 제공자가 반환한 정확한 ID를 사용하며, 저장된 모델도 새 키로 목록을 확인한 뒤 다시 선택합니다. 목록 조회 성공이 모든 생성 API 권한을 보장하지는 않습니다.

기본 URL 뒤에 `/responses`, `/messages`, `/chat/completions`를 직접 붙이지 마세요. 로컬 AI는 `/models`와 Chat Completions 호환 엔드포인트를 제공해야 합니다. 임의의 API 규격이나 별도의 OAuth 인증을 자동 지원하지는 않습니다.

연결 설정에 이름을 붙여 저장하고 나중에 전환할 수 있습니다. **API 키는 저장되지 않으므로 앱을 다시 실행하면 입력해야 합니다.** AI 서비스 이용 권한·사용량·요금은 해당 제공자 설정에 따릅니다.

## 글 추가 또는 선택 문장 교체

1. 추가하려면 한글에서 선택을 해제하고 커서를 놓습니다. 교체하려면 수정할 문장을 선택합니다.
2. 설정에서 **문서 읽기**를 누릅니다.
3. 적용 방식을 ‘커서 위치에 글 추가’ 또는 ‘선택한 문장 교체’로 정합니다.
4. AI에 보낼 문맥을 선택합니다. 기본값은 ‘문서 내용 보내지 않음’입니다. ‘전송할 문맥 확인’을 펼쳐 내용을 확인할 수 있습니다.
5. 설정을 닫고 질문을 입력해 **전송**을 누릅니다.
6. 대화에 나온 답변을 검토하고 직접 고친 뒤 **문서에 적용**을 누릅니다. 이전 답변은 ‘이 답변 편집’으로 다시 가져올 수 있습니다.
7. 설정의 **파일 저장**으로 저장합니다. 새 문서는 한글의 저장 대화상자에서 경로를 정하세요.

문서를 읽은 뒤 커서·선택 영역·본문이 바뀌면 적용이 중단됩니다. 문서를 다시 읽고 초안을 생성하세요. 다음 편집도 문서 읽기부터 시작합니다. 실수한 편집은 한글에서 `Ctrl+Z`로 되돌릴 수 있습니다.

## 사용량 바와 대화 이력

API가 알려주는 입력·출력·전체 토큰 수를 현재 연결 중 누적합니다. 한도 헤더가 있으면 가장 많이 사용한 한도 항목의 사용률과 남은 양을 표시합니다. 이 값은 **직전 응답 시점의 제한 구간 기준**이며 계정의 월간 잔액이나 전체 사용량이 아닙니다. 한도가 제공되지 않으면 줄무늬 바와 ‘한도 미제공’을 표시합니다. 토큰 수 자체가 없으면 미제공 횟수도 표시합니다.

키·주소·연결 프로필을 바꾸면 누적을 초기화합니다. 모델만 바꾸면 기존 누적은 유지하고 이전 모델의 한도 표시는 비웁니다. 설정의 **새 대화 시작**은 대화 기록만 비우고 누적은 유지합니다.

대화는 앱을 종료하면 사라집니다. 다음 요청에는 완성된 최근 10턴, 최대 60,000자를 함께 전송합니다. 문서 범위를 ‘보내지 않음’으로 바꾸더라도 최근 대화에는 이전 답변 내용이 포함될 수 있습니다. 이전 대화를 보내고 싶지 않으면 새 대화를 시작하세요.

## 패널 조작과 종료

| 조작 | 동작 |
| --- | --- |
| 설정 → 창에 붙이기 | 한글 창을 따라가는 모드와 독립 창 모드 전환 |
| 나란히 배치 | 현재 모니터에서 한글과 패널을 나란히 배치 |
| 한글로 이동 | 연결된 한글 창으로 포커스 이동 |
| `Ctrl+Shift+Space` | 숨겨진 패널 열기 |
| 트레이 아이콘 더블클릭 | 패널 열기 |
| 창의 X / 트레이의 종료 | 도우미 종료 |

다른 앱을 사용하거나 한글을 최소화하면 붙어 있는 패널이 숨겨집니다. 단축키가 다른 앱과 충돌하면 작업 표시줄 알림 영역의 트레이 메뉴를 사용하세요.

종료 전에 한글 문서를 직접 저장하세요. 도우미는 자동 저장하지 않으며 한글에 종료 명령을 보내지 않습니다. 나란히 배치했던 창은 가능한 경우 원래 위치·크기로 복구합니다.

## 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 한글에 연결되지 않음 | 한글 뷰어가 아닌 데스크톱 한글 설치 여부와 ‘버전 및 연결 점검’의 등록 정보 확인 |
| 예상과 다른 한글 버전이 열림 | 기본 연결은 Windows에 마지막 등록된 버전 사용. 별도 연결 식별자가 표시되는 경우 해당 항목 선택 |
| 편집에 필요한 API를 확인하지 못함 | 한글 버전별 지원 차이 확인. 현재 실제 편집 검증 버전은 2018 / 10.0.0.14850 |
| 문서 상태가 만료되었다고 나옴 | 커서와 선택 영역을 정한 뒤 문서를 다시 읽고 생성 |
| AI 요청 오류 | API 형식·URL·키·모델 ID·사용 한도 확인. 로컬 AI는 서버 실행 여부도 확인 |
| 401 인증 오류 | 유효한 해당 제공자의 API 키인지 확인. 모델 목록 재조회. 사용량 한도와는 다른 오류 |
| 패널이 보이지 않음 | `Ctrl+Shift+Space` 또는 트레이 메뉴로 열기 |
| 저장이나 연결이 멈춘 것처럼 보임 | 한글 쪽의 보안 확인창이나 저장 대화상자 확인 |
| 응답 시간 초과 | 실제 문서에 반영됐는지 먼저 확인한 뒤 다시 연결·읽기. 쓰기는 자동 재시도하지 않음 |

지원 범위는 일반 본문의 텍스트 편집입니다. 표·이미지·세부 서식은 별도로 확인해야 합니다. 문제가 계속되면 한글 버전, 도우미 버전, 오류 메시지와 재현 순서를 정리해 전달하세요.
