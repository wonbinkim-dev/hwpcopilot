# API 인증 오류와 사용량 한도

확인 날짜: **2026-11-02**. 아래 수치는 공개 문서의 기준이며 개인 계정의 실제 한도를 조회한 결과는 아닙니다. 실제 한도·잔액·요금은 해당 키가 속한 조직·프로젝트의 콘솔에서 확인하세요.

## 화면의 401 오류

OpenAI의 HTTP **401은 인증 실패**입니다. 모델 이름을 바꾸거나 기다리는 것으로 해결되는 사용량 초과 오류와는 다릅니다. 키가 삭제·취소되었거나 잘못 복사되었는지, OpenAI API용 키가 맞는지, 올바른 프로젝트와 접근 권한인지 확인하세요. [OpenAI 공식 오류 안내](https://developers.openai.com/api/docs/guides/error-codes)

앱에서 API 키를 다시 입력하고 입력칸 밖을 누르면 모델 목록을 조회합니다. ‘목록 불러오기’ 버튼으로 다시 확인할 수도 있습니다. 조회에 성공하면 직접 ID를 입력하는 대신 제공자가 반환한 모델을 선택합니다.

모델 목록 조회 권한과 생성 API 호출 권한은 다를 수 있습니다. 목록에 있다는 이유만으로 Responses 또는 Chat Completions의 모든 기능·결제 조건을 충족한다고 보장할 수는 없습니다. 앱은 명백한 이미지·오디오·임베딩 전용 ID를 제외한 텍스트 모델 후보를 표시하며, Gemini는 `generateContent` 지원 여부도 확인합니다.

| 결과 | 확인할 내용 |
| --- | --- |
| 401 | API 키 인증·발급 서비스·프로젝트 접근 권한 |
| 403 | 해당 API·모델에 대한 키 권한과 이용 가능 지역 |
| 404 | 기본 URL 또는 모델 존재 여부, 목록 다시 조회 |
| 429 / 일시적 제한 | 요청·토큰 한도와 재시도 시점 |
| 크레딧·금액 한도 오류 | 결제·잔액·조직/프로젝트 사용 금액 제한 |

앱은 제공자 오류의 원문이나 API 키를 화면에 표시하지 않고 구분된 안내를 보여줍니다. 유효하지 않은 키를 앱에서 자동으로 복구하거나 재발급하지는 않습니다.

## 한도 용어

| 항목 | 뜻 |
| --- | --- |
| RPM | 분당 요청 수 |
| TPM | 분당 토큰 수 |
| ITPM / OTPM | 분당 입력 토큰 / 출력 토큰 |
| RPD / TPD | 일일 요청 수 / 토큰 수 |
| 사용 금액 한도 | 월간 등 지정 기간의 API 지출 제한 |
| 컨텍스트 한도 | 한 번의 요청에 넣을 수 있는 입력·대화 길이로, 분당 할당량과는 별개 |

팀원이 같은 조직·프로젝트를 사용하면 키를 따로 발급해도 한도가 공유될 수 있습니다. 잔액, 호출 속도, 요청 하나의 길이를 구분해서 확인하세요.

## OpenAI

한도는 모델과 조직·프로젝트에 따라 다릅니다. [Limits 설정](https://platform.openai.com/settings/organization/limits)에서 본인 계정의 모델별 값을 확인하세요.

공식 문서의 **표준 Astra·Sol·Terra 계열 예시**는 다음과 같습니다. 다른 모델·특별 처리 모드나 개별 계정에 그대로 적용되는 표는 아닙니다.

| 유료 티어 | RPM | TPM | 조직 월간 사용 한도 |
| --- | ---: | ---: | ---: |
| Build | 5,000 | 1,000,000 | $500 |
| Launch | 10,000 | 4,000,000 | $5,000 |
| Grow | 15,000 | 40,000,000 | $200,000 |

월간 사용 한도는 무료로 지급되는 금액이 아닙니다. 결제 잔액이나 별도로 설정한 지출 상한과도 구분됩니다. 응답의 `x-ratelimit-*` 헤더에는 해당 요청의 남은 요청·토큰 한도 등이 포함될 수 있습니다. [OpenAI 공식 한도 문서](https://developers.openai.com/api/docs/guides/rate-limits)

## Claude

Messages API는 모델 계열별 **RPM·ITPM·OTPM**을 적용합니다. 조직 단위 제한이며 신규 계정의 Evaluation 티어는 공개 표준 티어보다 낮을 수 있습니다.

공개 월간 사용 금액 상한은 Start **$500**, Build **$1,000**, Scale **$200,000**입니다. 본인의 적용 값은 [Claude 한도 화면](https://platform.claude.com/usage/limits), 지출 상한은 Billing에서 확인하세요. 일시적 속도 제한과 월간 금액 상한은 복구 방법이 다릅니다. [Claude 공식 한도 문서](https://platform.claude.com/docs/en/api/rate-limits)

## Gemini

주요 기준은 **RPM·입력 TPM·RPD**입니다. 모델과 사용 티어에 따라 달라지며 **키가 아닌 프로젝트 단위**로 적용됩니다. RPD는 태평양 시간 자정 기준으로 초기화됩니다.

공식 문서가 실제 적용 한도 확인 위치로 안내하는 [Google AI Studio Rate Limit](https://aistudio.google.com/rate-limit)에서 사용할 프로젝트와 모델을 선택하세요. 로그인된 계정의 실시간 값을 확인하지 않았으므로 고정된 무료 요청 횟수로 단정하지 않습니다. [Gemini 공식 한도 문서](https://ai.google.dev/gemini-api/docs/rate-limits)

## OpenAI 호환·로컬 AI

호환 API의 한도는 실제 제공자의 정책을 따릅니다. 로컬 서버는 실행 설정, 메모리·GPU와 모델 컨텍스트 크기를 확인하세요. 앱은 `/models`를 제공하는 Chat Completions 호환 서버를 조회하며, 모델 목록 API가 없는 임의 규격은 지원하지 않습니다.

## 앱 자체 제한

0.3.0부터 사용량 바는 질문창 바로 위에 고정됩니다. 실제 응답의 `usage` / `usageMetadata`와 한도 헤더를 읽으며, 데이터가 없으면 한도나 월간 잔액을 추정하지 않습니다. 중단된 응답도 사용량이 보고되면 누적에 포함합니다. 이전 대화는 최근 10턴·60,000자까지만 다음 요청에 포함합니다.

이 앱은 문맥 **150,000자**, 적용 본문 **200,000자**, 모델 목록 조회 **30초**, 생성·한글 작업 대기 **120초** 제한을 둡니다. 이 값들은 제공자의 토큰·결제 한도와 별개입니다. 특히 한국어 글자 수를 API 토큰 수와 같은 값으로 볼 수는 없습니다.
